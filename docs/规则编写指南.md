# 规则编写指南

## 规则结构
每条规则包含以下核心字段：
```json
{
  "id": "uuid",
  "name": "规则名称",
  "category": "link|address|express|text",
  "enabled": true,
  "actionMode": "parse_and_open|direct_open|webview_resolve_and_open|clipboard_write|notify_only",
  "matchRegex": "匹配正则",
  "parameterRegex": "参数提取正则",
  "triggerRegexes": ["触发正则数组"],
  "extractionRegexes": ["提取正则数组"],
  "parseAfterRedirect": false,
  "matchAllTriggers": false,
  "delayMillis": 0,
  "priority": 0,
  "group": "分组/标签",
  "excludeRegex": "排除规则（命中则跳过）",
  "regexOptions": "i|s|m",
  "notificationMode": "none|normal|live",
  "sourcePackages": "来源App包名白名单",
  "activeTimeStart": "HH:mm",
  "activeTimeEnd": "HH:mm",
  "clearClipboardAfterJump": false,
  "target": {
    "type": "url|intent",
    "template": "目标模板",
    "packageName": "目标包名",
    "action": "android.intent.action.VIEW"
  },
  "createdAt": 1710000000000
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | string | 规则名称 |
| `category` | string | 分类：`link` 链接 / `text` 文本 / `address` 地址 / `express` 快递 |
| `enabled` | boolean | 是否启用（默认 true）|
| `actionMode` | string | 执行模式（见下，默认 `parse_and_open`）|
| `matchRegex` | string | 主匹配正则（必填）|
| `parameterRegex` | string | 参数提取正则（捕获组供模板变量使用）|
| `triggerRegexes` | string[] | 触发条件正则列表（配合 `matchAllTriggers`）|
| `extractionRegexes` | string[] | 提取正则列表（捕获组供 `${r1}` 等使用）|
| `parseAfterRedirect` | boolean | 重定向后继续解析（默认 false）|
| `matchAllTriggers` | boolean | 所有触发正则需同时命中（默认 false = 任一命中）|
| `delayMillis` | int | 延迟跳转毫秒数 0-5000（默认 0 = 立即）|
| `priority` | int | 优先级：越大越优先（默认 0）|
| `group` | string | 分组/标签 |
| `excludeRegex` | string | 排除规则：命中则跳过（负规则）|
| `regexOptions` | string | 正则选项：`i` 忽略大小写 / `s` DOTALL / `m` MULTILINE（可组合如 `is`）|
| `notificationMode` | string | 规则级通知模式（覆盖全局设置；null = 跟随全局）|
| `sourcePackages` | string | 来源 App 包名白名单（逗号分隔；空 = 不限来源）|
| `activeTimeStart` / `activeTimeEnd` | string | 生效时间段（`HH:mm`；空 = 不限）|
| `clearClipboardAfterJump` | boolean | 跳转后清空剪贴板（默认 false）|
| `target` | object | 目标：`type`（`url`/`intent`）、`template`、`packageName`、`action` |

## 执行模式

1. **parse_and_open**：解析链接后打开（详情页零网络提取，如抖音/快手/小红书详情，默认）
2. **direct_open**：直接打开目标应用
3. **webview_resolve_and_open**：用隐藏 WebView 解析短链接重定向后打开（短链场景）
4. **clipboard_write**：将模板渲染结果写回剪贴板（如复制验证码自动提取纯数字）
5. **notify_only**（v1.138）：仅发通知栏通知，不跳转、不改剪贴板（如取件码/取货码/口令码场景）

## 正则编写规则

### matchRegex
- 用于判断文本是否匹配规则
- 示例：`.*BV1\w+.*` 匹配包含BV号的内容

### parameterRegex
- 用于提取参数，捕获组按顺序命名为 `${p1}`, `${p2}`
- 示例：`.*(BV1\w+).*` 提取BV号到 `${p1}`

### triggerRegexes（可选）
- 替代 matchRegex 的触发条件数组
- 任一匹配即触发（开启 `matchAllTriggers` 后需全部匹配）

### extractionRegexes（可选）
- 替代 parameterRegex 的提取规则数组
- 支持多模式提取

## 模板变量

- `${p1}`, `${p2}` - 按顺序的捕获组参数
- `${r1}` - 第一个提取规则的第一个捕获组
- `${r1_1}` - 第一个提取规则的第一个捕获组（精确索引）
- `${input}` - 原始输入文本
- `${url:input}` - 从完整复制内容中提取第一个 URL
- `${redirectUrl}` - WebView 解析后的重定向 URL
- `${raw:变量名}` - 不进行 URI 编码的原始值
- `${pkg}` - 当前规则的目标应用包名
- `${time:yyyy-MM-dd HH:mm}` - 当前时间（格式自定，如 `${time:HH:mm:ss}`）
- `${lower:key}` / `${upper:key}` - 参数转小写 / 大写
- `${encode:key}` - 参数做 URL 编码
- 模板变量未提取到值时会替换为空，例如 `?pwd=${r2}&` 会保留为 `?pwd=&`

## 示例规则

### Bilibili视频跳转
```json
{
  "name": "Bilibili视频",
  "category": "link",
  "actionMode": "parse_and_open",
  "matchRegex": ".*BV1\\w+.*",
  "parameterRegex": ".*(BV1\\w+).*",
  "target": {
    "type": "url",
    "template": "bilibili://video/${p1}",
    "packageName": "tv.danmaku.bili"
  }
}
```

### 地址跳转
```json
{
  "name": "高德地图地址",
  "category": "address",
  "actionMode": "webview_resolve_and_open",
  "matchRegex": ".*amap\\.com.*",
  "parameterRegex": "",
  "target": {
    "type": "url",
    "template": "${redirectUrl}",
    "packageName": "com.autonavi.minimap"
  }
}
```

### 直接打开App
```json
{
  "name": "打开微信",
  "category": "link",
  "actionMode": "direct_open",
  "matchRegex": "",
  "parameterRegex": "",
  "target": {
    "type": "url",
    "template": "",
    "packageName": "com.tencent.mm"
  }
}
```

### 剪贴板改写（复制验证码自动提取纯数字）
```json
{
  "name": "验证码提取",
  "category": "text",
  "enabled": true,
  "actionMode": "clipboard_write",
  "matchRegex": ".*验证码.*(\\d{6}).*",
  "parameterRegex": ".*(\\d{6}).*",
  "target": {
    "type": "url",
    "template": "${p1}"
  }
}
```

### 取件码通知（仅通知，v1.138）
```json
{
  "name": "取件码通知",
  "category": "text",
  "enabled": true,
  "actionMode": "notify_only",
  "priority": 100,
  "matchRegex": ".*(?:取件码|取货码|提货码|口令码|取餐码|收货码|开柜码)(?:是|为)?[:：]?\s*[『"“「]?[0-9A-Za-z]{1,16}(?:-[0-9A-Za-z]{1,8}){0,3}[』"”」]?.*",
  "extractionRegexes": [".*(?:取件码|取货码|提货码|口令码|取餐码|收货码|开柜码)(?:是|为)?[:：]?\s*[『"“「]?([0-9A-Za-z]{1,16}(?:-[0-9A-Za-z]{1,8}){0,3})[』"”」]?.*"],
  "target": {
    "type": "url",
    "template": "${r1}"
  }
}
```
> 取件码格式支持：纯数字（52976694）、横杠货架号（3-3-1020）、字母数字（A02-0529）、引号包裹（『52976694』）

### 快递单号识别（直达菜鸟查件）
```json
{
  "name": "快递单号-菜鸟查件",
  "category": "express",
  "enabled": true,
  "actionMode": "direct_open",
  "priority": 100,
  "matchRegex": "\\b(?:SF)\\d{12,15}|(?:YTO|YT)\\d{13}|(?:JD)\\d{13,15}\\b",
  "parameterRegex": "\\b([A-Z]{2,6}\\d{9,20})\\b",
  "target": {
    "type": "url",
    "template": "",
    "packageName": "com.cainiao.wireless"
  }
}
```

## 注意事项

1. 正则使用 Kotlin/Java 正则语法
2. 特殊字符需转义（如 `\.` 匹配点号）
3. 测试正则时使用在线工具验证
4. 优先使用 `triggerRegexes` 和 `extractionRegexes` 提高灵活性
5. WebView 模式适用于需要网页解析的短链接
6. `priority` 越大越优先，特定规则建议设置高于通配规则（如 100），避免被通用规则抢占
7. 规则命中后 30 秒内同目标同内容不重复跳转（防循环，无需配置）
